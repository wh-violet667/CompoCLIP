# 2 相关工作

## 2.1 视觉-语言对比预训练

CLIP[1] 用 4 亿图文对训练双塔模型，图像编码器与文本编码器分别输出归一化向量，训练目标是 batch 内的对称 InfoNCE。ALIGN[2] 用噪声更大的 18 亿图文对验证了“规模换质量”的可行性；OpenCLIP[3] 与 LAION-5B[4] 把数据与训练代码开放，使学术环境可以复现 ViT-B/32、ViT-L/14 等配置。BLIP[11]、BLIP-2[12]、CoCa[13] 则在对比学习之外加入生成/描述目标，试图让模型学到更细粒度的跨模态对应。

这些模型在零样本检索与分类上表现很强，但它们的训练信号始终是“整句—整图”的二分类式匹配。只要负例在词袋上差异足够大，模型就能靠名词匹配取得很低损失；词序、属性绑定、关系方向等结构信息没有独立的监督项。这是后文所有组合性失败的共同根源。

## 2.2 组合性评测基准

**Winoground**[5] 是最早专门针对 visio-linguistic compositionality 的基准之一。它由 400 组专家构造的最小对立对组成，每组两张图、两句 caption，评估 text / image / group 三个准确率。group 准确率要求模型同时选对两张图对应的句子，随机基线为 1/6 ≈ 16.7%。Winoground 的难点在于：两张图往往只差一个关系方向或属性绑定，词袋高度重叠。

**ARO**[6] 把组合性拆成四个子集：VG-Relation（关系方向）、VG-Attribution（属性错配）、COCO-Order 与 Flickr-Order（词序）。前两个子集基于 Visual Genome[14] 的 region caption 构造，后两个子集对 COCO[15]/Flickr30k[16] 的 caption 做词序扰动。ARO 的核心结论是：CLIP 在 order 子集上接近随机，说明它更像“词袋模型”；作者进一步提出 NegCLIP，用硬负例微调来缓解。

**SugarCrepe**[7] 指出，早期基准的负例可以由单字替换、句子长度等浅层统计量区分，模型可以“hack”基准而不真正理解组合。它用 LLM 生成更自然的负例，并要求正负句在词法上尽量接近。**SugarCrepe++**[8] 进一步把“语义改变”与“词法改变”分开：模型不仅要拒绝错误语义，还要对同义改写保持稳定。这带来一个评测陷阱：同义改写句（caption2）绝不能被当作负例，否则准确率会虚高；本项目在数据准备阶段专门修正了这一点（见 `docs/decision-log.md` D0-2）。

## 2.3 组合性失败的机制解释

Yuksekgonul 等[6] 把失败归因于“bag-of-words 捷径”：对比学习只要求区分不同图的句子，而不同图的名词分布差异很大，模型无需编码词序即可降低损失。后续工作从表征几何角度补充了两种解释：

- **模态鸿沟（modality gap）**：图像与文本嵌入分别聚集在各自锥形区域，跨模态相似度的绝对值不可比，点积读数对词序变化不敏感。
- **信息存在但不可线性读出**：部分工作发现，冻结特征上训练线性探针或轻量适配器，能显著提升组合性指标[22,24]。这说明编码器并非完全没有结构信息，而是预训练目标没有把它“摆到”点积可直接读取的位置。

第 3 章的 0-A/0-B 就是围绕这两种解释设计的：0-B 用保持词袋的变换测“读法”，0-A 用线性探针测“信息在不在”。

## 2.4 改进方法

**数据侧**：NegCLIP[6] 用依存分析构造硬负例；CyCLIP[9] 加入跨模态与跨样本的循环一致性约束；SugarCrepe[7] 用 LLM 生成自然负例。这类方法直接改变训练分布，代价是需要重新训练或微调。

**模型侧**：Counting CLIP[10] 加入计数分支；BLIP-2[12] 用 Q-Former 对齐冻结编码器与 LLM；区域级方法引入 detection/segmentation 监督。代价是参数与推理成本上升。

**参数高效适配**：LoRA[19]、线性/MLP adapter、蒸馏[20] 只训练少量参数，适合课程项目的算力预算。其前提是“信息已经在表征里”，因此需要 0-A 这样的探针先验证上限。

## 2.5 研究空白

现有工作大多直接报告基准准确率，缺少三个层面的细粒度证据：（1）在**严格保持词袋**的条件下，不同词序变换的敏感度差异；（2）失败是“完全不会”还是“近失手”，这决定改进方法是重训练还是重读数；（3）不同基准的失败结构是否一致，即基准本身是否在测同一种能力。本文的 0-B/0-C 与 E0 逐样本分析正是为填补这三点。
